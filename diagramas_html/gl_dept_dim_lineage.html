  • Two more reusable placeholder-creation templates exist with no caller identified anywhere in the available material
  • The only load process found for this table is a one-time setup from 2013, the same reusable pattern already found on other dimensions in this project, built by the same author. Confirmed to have no active schedule and no live path that reaches it in the process files that reference it: it is a historical setup template, not the table's real ongoing load process
