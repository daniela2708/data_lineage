  • A safety-net process that adds placeholder supplier records is confirmed to feed this table.   • No generic 'unknown supplier' placeholder row exists on this table, unlike most other reference tables reviewed so far in this project, and no duplicate supplier codes were found
  • This table was not part of the 2015-2016 wave of deliberate shutdowns documented for several other reference tables in this project; no such note exists for it in that record. This is an absence-based conclusion, which carries less weight than a positive confirmation would
